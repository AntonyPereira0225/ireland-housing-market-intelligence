# Data

The project uses official Central Statistics Office (CSO) PxStat data.

## Raw source files

Place the downloaded CSV files in `data/raw/` using these filenames:

- `HPM09.csv` — Residential Property Price Index
- `NDQ06.csv` — New Dwelling Completions

Raw source files are intentionally **not committed** to the repository. This keeps the project lightweight and encourages reproducible retrieval from the official source.

## Generated processed files

Running the Python workflow creates:

- `data/processed/hpm09_clean.csv`
- `data/processed/ndq06_clean.csv`
- `data/processed/market_intelligence_quarterly.csv`

These intermediate processed files remain local.

## Committed Power BI-ready datasets

The final small analytical exports used by the Power BI dashboard are committed in `data/power_bi/`:

- `market_intelligence_quarterly.csv`
- `local_authority_completions.csv`
- `national_house_type_completions.csv`

They are generated by `src/08_power_bi_exports.py` and provide a compact, reviewable analytical layer without committing the larger raw source datasets.

Run the scripts in numerical order from the repository root to reproduce the full workflow.
